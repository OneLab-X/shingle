> **salon-spa** category. The phone number is in ACMA's Victorian range reserved for fiction;
> the domain and booking link use the reserved `.example` TLD.

| | |
|---|---|
| Category | `salon-spa` → schema.org `HairSalon` |
| Pages | Single page: hero, treatments and prices, team, visit |
| Direction | **Quiet Luxury**: Cormorant Garamond + Jost, hairlines, very generous space |
| Palette | **Rose Clay** (light + dark) |
| Primary CTA | Book online (booking link from `decisions.booking_url`) |

## Design rationale
A considered salon sells calm and care, so the page uses fewer words and more air: large
Cormorant headings with italic accents in clay rose, Jost set small with wide tracking for
labels, and long section gaps. The **signature element** is a fine hairline frame inset around
the whole viewport on desktop, plus vertical small-caps section labels in the margin, like a
printed salon card. Treatments are a clean three-column price list with durations, exactly as
the owner gave them, and the skin-test and cancellation notes sit right under the prices.

## Facts vs placeholders
Treatments, durations, prices, team names and roles, and policies come from `business.json`.
Not invented: product brands, qualifications, treatment outcomes, reviews. Still to fill:
