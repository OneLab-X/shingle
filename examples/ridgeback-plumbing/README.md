# Ridgeback Plumbing & Gas (example)

> Fictional business. Generated by Shingle from [`business.json`](business.json) to show the
> **contractor-home-services** category. The mobile number is from ACMA's range reserved for
> fiction; the domain uses the reserved `.example` TLD.

| | |
|---|---|
| Category | `contractor-home-services` → schema.org `Plumber` with `areaServed` |
| Pages | Single page: hero, emergency band, services, process, areas, quote |
| Direction | **Swiss Grid**: Archivo + IBM Plex Sans, 2px radius, visible 12-column grid |
| Palette | **Safety Orange** (light only) |
| Primary CTA | Call now; secondary: send photos on WhatsApp; quote form via Web3Forms |

## Design rationale
Someone with a burst pipe needs the phone number, now. The number sits in a sticky header and
in the hero, and a hi-vis band announces 24/7 emergency call-outs. The **signature element** is
the oversized index numerals (01–06 for services, 01–03 for how a job works) hanging in the
grid, over a visible hairline grid in the hero: it reads like a technical drawing and makes a
long service list scannable. Workwear orange on warm white is impossible to miss; no dark mode,
because this palette is about daylight contrast.

It is a service-area business with no public address, so there is no map pin: the page lists
the suburbs served instead, and JSON-LD uses `areaServed`.

## Facts vs placeholders
Services, process, emergency hours, quote and payment wording come from `business.json`.
Not invented: licence number, insurance cover, years in business, response times, reviews.
