# Marigold Kitchen (example)

> Fictional business. Generated by Shingle from [`business.json`](business.json) to show the
> **restaurant** category. Phone numbers use Ofcom's range reserved for fiction; the domain uses
> the reserved `.example` TLD.

| | |
|---|---|
| Category | `restaurant` → schema.org `Restaurant` |
| Pages | Single page: masthead, story, menu, photos, visit, questions, booking |
| Direction | **Broadsheet**: Fraunces + Source Serif 4, no radius, rules instead of cards |
| Palette | **Saffron & Ink** (light + dark) |
| Primary CTA | Book a table (phone) |

## Design rationale
A family Goan restaurant lives on its menu and its story, so the page reads like the front
page of a local paper. The **signature element** is the masthead: the name set huge across the
full width, a double rule, then a dateline with the live open status and the phone number.
The menu is set in three newspaper columns with dotted leaders so prices line up, and the
story opens with a drop cap. Saffron on warm paper echoes turmeric and printed menus;
dark mode inverts to ink with a brighter saffron so it still feels like evening service.

Typography carries the page, so it already looks finished before the owner sends photos:
the four photo slots are labelled placeholders sized for the real shots.

## Facts vs placeholders
Everything on the page comes from `business.json` (menu, prices, story, FAQ, hours). Nothing
else is claimed: no reviews, no awards, no "best curry in London". Still to fill:
