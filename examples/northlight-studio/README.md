# Northlight Studio (example)

> Fictional business. Generated by Shingle from [`business.json`](business.json) to show the
> **photographer** category. The phone number is in Ofcom's Edinburgh range reserved for
> fiction; the domain uses the reserved `.example` TLD.

| | |
|---|---|
| Category | `photographer` → schema.org `ProfessionalService` + Wikidata photographer type |
| Pages | Single page: intro, portfolio, about, services, enquiry |
| Direction | **Gallery**: Instrument Serif + Instrument Sans, no radius, no borders |
| Palette | **Darkroom** (light + dark) |
| Primary CTA | Check my date (email) |

## Design rationale
For a photographer the work is the website, so everything else steps back: small uppercase
captions, a quiet italic serif, neutral greys that will not fight the colours in the photos,
and a safelight-red accent used only for numbers. The **signature element** is an asymmetric
grid of tall, wide and square slots with numbered captions ("03 — Elopement on the ridge,
*Isle of Skye*"); on phones it becomes a horizontally swiped contact sheet. Until Mairi sends
her images, each slot is a labelled frame naming the exact shot to drop in. She travels to
clients, so there is no map pin; the page lists where she works instead.

## Facts vs placeholders
