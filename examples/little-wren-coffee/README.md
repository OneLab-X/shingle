## Design rationale
A neighbourhood coffee bar is personal, so the page should feel made by hand rather than
assembled. Two **signature elements**: a hand-drawn underline that draws itself under one
key word per heading ("window seat", "counter", "find us"), and a round **hours stamp** with
the real opening hours set around the rim, like the rubber stamp on a loyalty card. It is
built from `hours`, so it can never disagree with the hours table. Espresso brown on cream,
with a caramel accent, keeps it warm without beige-on-beige mush.

## Facts vs placeholders
Menu and prices, the good-to-know notes, and directions come from `business.json`. Not
invented: roaster names, "organic"/"local" claims, reviews. Still to fill:
