# Saltmarsh Railway Society (example)

> Fictional business. Generated by Shingle from [`business.json`](business.json) to show the
> **Postcard** direction on a **nonprofit**. The phone number is in the Ofcom drama range
> (01632 960xxx); the domain uses the reserved `.example` TLD.

| | |
|---|---|
| Category | `nonprofit` → schema.org `NGO` (shown as "Heritage railway") |
| Pages | Single page: the line, volunteer roles, visit |
| Direction | **Postcard**: Bevan + Josefin Sans, 6px radius, air-mail stripes |
| Palette | **Postcard Stamp** (light + dark) |
| Primary CTA | Volunteer with us (email) |

## Design rationale
A railway that people send cards from should look like one. The **signature element** is the
hero as a postcard: an air-mail striped frame, a perforated stamp with the society's initial, a
round postmark whose text is built from the real place, running days and season in
`business.json`, and an address block on ruled lines. Stations and volunteer roles are smaller
cards in the same stripes. Cream card stock, navy ink and stamp red keep it warm without sunset
gradients; there are no photos, so nothing is staged.

## Facts vs placeholders
Stops, roles, running days and season come from `business.json`. Not invented: fares,
timetable, visitor numbers, awards, reviews. Still to fill:

- Fares and the season timetable
- Registration number and a donation link (if the society has one)
