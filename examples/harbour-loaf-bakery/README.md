# Harbour Loaf Bakery (example)

> Fictional business. Generated by Shingle from [`business.json`](business.json). The phone number
> is in Ofcom's Bristol range reserved for fiction; the domain uses the reserved `.example` TLD.

This example exists to exercise the **image pipeline** end to end in CI.

| | |
|---|---|
| Category | `cafe` → schema.org `CafeOrCoffeeShop` |
| Pages | Single page: hero photo, three photo slots, visit |
| Direction | **Handmade** with the **Espresso & Cream** palette |

## What the photos are
The three files in `public/images/` are **flat-colour test images generated by a script**, not
photographs: no stock or AI pictures are ever used. Their alt text says so. They were made with
GPS and camera data in the original files, then imported with

```
python3 ../../skills/shingle/scripts/import_images.py <folder> --site .
python3 ../../skills/shingle/scripts/import_images.py --apply-alt answers.json --site .
```

which strips that metadata (`audit_site.py` fails the build if any GPS data survives in `dist/`),
gives each file a clean name, and records `width`, `height`, `subject` and the confirmed `alt` in
`business.json`. The page shows them through `<Photo slot="…">`, which resizes them and serves
responsive WebP. One slot, "Pastry case", has no photo and stays a visible placeholder.
