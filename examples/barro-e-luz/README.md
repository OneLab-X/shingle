# Barro & Luz (example)

> Fictional business. Generated by Shingle from [`business.json`](business.json) to show a
> **multi-language** site (Portuguese + English) in the **ecommerce-boutique** category. The phone
> number `21 000 0000` is deliberately not a working number; the domain uses the reserved
> `.example` TLD.

| | |
|---|---|
| Category | `ecommerce-boutique` → schema.org `HomeGoodsStore` |
| Languages | `["pt", "en"]`: `/pt/` (default) and `/en/`; `/` redirects to `/pt/` |
| Pages | One page per language: hero, pieces, workshop, questions, visit |
| Direction | **Handmade**: Young Serif + Nunito Sans, 16px radius, price stickers |
| Palette | **Terracotta Sun** (light + dark) |
| Primary CTA | Call, or directions to the shop |

## Design rationale
A ceramics shop sells things people want to hold, so the page borrows the object: an **azulejo
tile** motif, drawn in SVG with the palette's own colours, makes the hero mosaic and a tile band
that divides the page. Pieces sit on a loose grid with every second card nudged down, and the price
is a round "sticker" tilted on the corner of each card, like a price label on a shelf. Terracotta
and teal come straight from glazed tiles. Photos are labelled placeholders sized for the real
product shots, so the page already works before they arrive.

## How the two languages work
- **One page file** (`src/pages/[lang]/index.astro`) renders every language with
  `getStaticPaths`; nothing is copied per language.
- **Facts** are written once in Portuguese. The English text is a
  `translations.en` overlay in business.json; **prices, phone and email are identical** in both
  (the validator rejects a translated price).
- **Interface text** (day names, "Open now", "Show map", the skip link) comes from the plugin's
  `ui-strings/pt.json` and `en.json`.
- Every page has absolute, reciprocal `hreflang` alternates for `pt`, `en` and `x-default`
  (Portuguese), a self-referencing canonical, `og:locale` + `og:locale:alternate`, and appears in
  the sitemap with `xhtml:link` alternates. `audit_site.py` checks all of it.
- The English text is a **draft written by Claude** (`"review": "draft"`), so `/en/` shows a
  visible "a native speaker should review this" notice until someone sets `review` to `"reviewed"`.
