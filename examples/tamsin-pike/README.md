> **Ledger** direction on a `generic-local-business`. The phone number is in the Ofcom
> drama range (0117 496 0xxx); the domain uses the reserved `.example` TLD.

| | |
|---|---|
| Category | `generic-local-business` → schema.org `LocalBusiness` (shown as "Bookkeepers") |
| Pages | Single page: services, a month in the books, visit and contact |
| Direction | **Ledger**: Spline Sans Mono + Newsreader, 0 radius, 1px rules |
| Palette | **Ledger Green** (light + dark) |
| Primary CTA | Book a free call (phone) |

## Design rationale
A bookkeeper sells exactness, so the page is a set of ledger folios. The **signature element**
is ruled paper: a faint 28px ruling, a double green margin rule, and a "Folio 01 · Services"
label on each section. Services, the monthly rhythm and opening hours are real tables with
tabular figures and dotted leaders, and each closes with a total row built only from
`business.json` (number of services, hours open per week). Mono headings and a readable serif
body keep it plain-spoken rather than cold; no photos are needed.

## Facts vs placeholders
Services, rhythm, process and the pricing statement come from `business.json`. Not invented:
prices, client numbers, awards, reviews. Still to fill:
