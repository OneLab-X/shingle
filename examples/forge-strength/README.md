# Forge Strength Club (example)

> Fictional business. Generated by Shingle from [`business.json`](business.json) to show the
> **gym-fitness** category. The phone number is in the US 555-01xx fiction range; the domain
> uses the reserved `.example` TLD.

| | |
|---|---|
| Category | `gym-fitness` → schema.org `ExerciseGym` |
| Pages | Single page: hero, marquee, classes, weekly timetable, start here, visit |
| Direction | **Poster**: Anton + Work Sans, 3px borders, offset solid shadows |
| Palette | **Volt Graphite** (dark mode is the hero mode) |
| Primary CTA | Book a free intro (stated in facts) by phone or text |

## Design rationale
A strength gym should feel loud and physical. Huge uppercase Anton, heavy borders and offset
shadows make it read like a gig poster, and volt lime on graphite looks best in dark mode,
which is the mode the gym's audience mostly browses in at night. The **signature element** is
a tilted marquee band repeating the gym's own words from `facts.offer_words` ("Strength ·
Boxing · Conditioning · Open 5:30am"); it stops moving for visitors who prefer reduced motion.
The weekly timetable is a real table (scrolls sideways on phones) built from facts.

## Facts vs placeholders
Classes, timetable, the free intro, hours and parking come from `business.json`. Not invented:
membership prices, coach names, transformation claims, member counts. Still to fill:
